Política de Privacidade

Última atualização: 02 de julho de 2026

🔒 Resumo: Este site é um cronômetro simples. Armazenamos apenas sua preferência visual (tema claro/escuro) no navegador, com seu consentimento. Nenhum dado é enviado para servidores externos.

1. Dados Armazenados Localmente

Com o seu consentimento, este site armazena no seu navegador (localStorage):

  • Preferência de tema (claro/escuro) — chave: countdown-theme-preference
  • Registro de consentimento — chave: lgpd-consent

Este armazenamento é exclusivamente local. Nenhum dado é transmitido para servidores, APIs ou terceiros.

2. Finalidade do Armazenamento

A preferência de tema é salva para que, ao retornar ao site, sua escolha visual seja preservada. Sem este dado, o tema padrão (escuro) é usado a cada visita.

3. Cookies

Este site não utiliza cookies de rastreamento, publicidade, analytics ou funcionalidade. Apenas o armazenamento local descrito acima é utilizado.

4. Dados Técnicos (Logs do Servidor)

O servidor web pode registrar temporariamente o endereço IP do visitante para fins de operação e segurança. Estes logs são armazenados apenas pelo tempo necessário e não são compartilhados com terceiros.

5. Fontes e Recursos

Todos os recursos (fontes, CSS, imagens) são servidos localmente pelo próprio site. Nenhuma requisição externa é feita durante o carregamento.

6. Compartilhamento com Terceiros

Não compartilhamos dados pessoais com terceiros. Não utilizamos Google Analytics, Facebook Pixel, ou qualquer serviço de rastreamento.

7. Seus Direitos (LGPD - Lei 13.709/2018)

Você tem direito a:

  • Confirmar a existência de tratamento de dados
  • Acessar os dados armazenados sobre você
  • Solicitar a exclusão dos dados — para remover o que foi salvo no seu navegador, utilize a opção "Recusar" no banner de consentimento ou limpe o localStorage do seu navegador
  • Revogar o consentimento a qualquer momento

Você pode gerenciar o armazenamento local do seu navegador a qualquer momento através das configurações de privacidade do seu navegador.

8. Base Legal

O tratamento de dados é realizado com base no consentimento do titular (Art. 7º, I da LGPD), obtido através do banner exibido na primeira visita.

10. Alterações
